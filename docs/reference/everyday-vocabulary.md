# Everyday Vocabulary

Short English–Spanish vocabulary tables grouped by situation.

## In the classroom

| English | Español |
|---|---|
| teacher | profesor/a |
| classmate | compañero/a de clase |
| notebook | cuaderno |
| pencil | lápiz |
| board | tablero / pizarra |
| classroom | salón / aula |
| email address | dirección de correo |
