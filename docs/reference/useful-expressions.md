# Useful Expressions

Short functional phrases for real situations. Some are **fixed expressions** to recognize and use without analyzing every grammatical component.

| Situation | English | Español |
|---|---|---|
| Greeting | Hello. / Hi. | Hola. |
| Meeting someone | Nice to meet you. | Mucho gusto. |
| Asking for repetition | Sorry? | ¿Perdón? |
| Asking for spelling | How do you spell that? | ¿Cómo se deletrea eso? |
| Classroom instruction | Open your book, please. | Abre tu libro, por favor. |
| Asking origin | Where are you from? | ¿De dónde eres? |
| Responding | I'm from Colombia. | Soy de Colombia. |
| Gratitude | Thank you. | Gracias. |

For guided dialogue practice, see [Elementary Unit 1](../elementary/index.md).
