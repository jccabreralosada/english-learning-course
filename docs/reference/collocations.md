# Collocations

Common word combinations. These examples are for recognition and quick lookup.

| Combination | Español | Example |
|---|---|---|
| make a mistake | cometer un error | I make a mistake. |
| do homework | hacer tareas | I do homework. |
| take a break | tomar un descanso | Take a break. |
| have a question | tener una pregunta | I have a question. |

**Note:** The expressions are quick-reference items; not all grammatical patterns in the examples have been taught in Unit 1.
