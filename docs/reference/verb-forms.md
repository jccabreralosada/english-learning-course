# Verb Forms

Searchable mini-dictionary of verbs. The columns will support **base form**, **Past Simple**, **past participle** and a concise Spanish meaning. The table below is a small original starter set, **not** a complete irregular-verb list.

| Base form | Past Simple | Past participle | Español |
|---|---|---|---|
| be | was / were | been | ser / estar |
| do | did | done | hacer |
| go | went | gone | ir |
| have | had | had | tener / haber |
| work | worked | worked | trabajar |

**Key:** *Base form* = dictionary form; *Past Simple* = past-tense form; *past participle* = form used in several later constructions. Past forms are **quick-reference entries**, not topics taught in Elementary Unit 1.

For present *be* and beginner explanations, see [Grammar Rules](grammar-rules.md) or [1A](../elementary/unit_01/lesson_a.md).
