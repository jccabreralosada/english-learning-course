# English Quick Reference — information architecture

**Scope:** A public lookup library, separate from long-form lessons. It contains no self-study exercises, assessment items, learner progress, PR statuses or private source identifiers.

## Category contract

| Path under `docs/reference/` | Data shape | Initial coverage |
|---|---|---|
| `verb-forms.md` | base / Past Simple / past participle / Spanish | tiny original regular/irregular sample |
| `everyday-vocabulary.md` | English / Spanish by context | classrooms, days, countries |
| `grammar-rules.md` | compact pattern / example | 1A–1C |
| `phrasal-verbs.md` | phrase / Spanish / example | four introductory lookup entries |
| `collocations.md` | combination / Spanish / example | four introductory entries |
| `useful-expressions.md` | situation / English / Spanish | Unit 1 expressions |
| `confusing-words.md` | pair / distinction / example | Unit 1 lexical distinctions |
| `numbers-dates.md` | number / written English | 0–100 samples; dates/time deferred |

## Authoring and release rules

- Prefer short tables, meaningful headings, original examples and at most one concise usage note per table.
- Pages may list verified linguistic reference facts for advanced topics **without** implying the related lesson has been authored or studied. Link only to existing published lessons.
- Avoid duplicate full lists. When a category grows, introduce alphabetical headings or context subpages instead of making one enormous table.
- Keep the existing MkDocs Material search index and native navigation. Do not add custom JavaScript or a second search engine without evidence that navigation fails.
- Language data should be checked for correctness. Reserve textbook-index claims for the master curriculum, not reference dictionary entries. Do not reproduce textbook excerpts.
- Every future addition goes through independent editorial review; check table rendering, internal links, 390 px mobile, 1440 px desktop, and both color schemes.
- Do not confuse lookup entries, learner mastery and formal assessment. No grades or personal records here.

## Tutor-protocol separation

The learner-facing 1A/1B/1C pages now contain concise **Practise with your tutor** tables. Full operational guidance is preserved in `governance/unit_01_tutor_protocol.md` for the separate tutor project to consult when needed. Do not place operational scoring or private training data in public pages.
