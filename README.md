# English Learning Course

Original, progressively structured English-learning materials, from **Elementary** through **Advanced Plus**, inspired by the *English File* progression and mapped to CEFR learning outcomes.

**What this repository contains:** curriculum, pedagogical and assessment guidelines, lesson sources, visuals, vocabulary and non-graded self-study exercises. The public study site will be published using **MkDocs + Material for MkDocs on GitHub Pages**.

**What it does not contain:** commercial textbook scans, private learner data, grading history, or individual performance records. Personal progress belongs in a separate private repository.

Changes to `docs/` build through the GitHub Actions workflow in `.github/workflows/pages.yml`. GitHub Pages must use **GitHub Actions** as its source under repository Settings → Pages.
